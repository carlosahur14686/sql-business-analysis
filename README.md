# SQL Business Analysis

A practical SQL project for business reporting and data analysis.

## What it demonstrates

- Relational table design
- Primary and foreign keys
- JOIN and LEFT JOIN
- GROUP BY and HAVING
- Aggregation with SUM, AVG and COUNT
- Filtering and sorting
- Revenue analysis
- Detection of products without sales
- Practical business reporting

## Project structure

- `schema.sql` — creates the database structure
- `sample_data.sql` — inserts example products and sales
- `queries.sql` — contains business-analysis queries
- `.gitignore` — excludes local databases, environment files and secrets

## Business questions answered

1. Which products generate the most revenue?
2. What is total revenue by category?
3. Which active products have no sales?
4. What is the average selling price by product?

## Example technologies and concepts

SQL • Relational Databases • JOIN • GROUP BY • Aggregation • Data Analysis • Reporting • Data Validation

## Project purpose

This repository demonstrates practical SQL problem solving using a small business scenario inspired by real operational needs. The dataset is fictional and contains no private business information.
